# CodeMaster - Interactive Digital Study Guide & Quiz Engine

## Project choice
Subject: Basic Coding

## Requirements covered
1. Organized subject modules with key terms, summary notes, and diagrams/charts.
2. Multiple-choice quiz for each module.
3. Immediate visual feedback for correct/incorrect answers with explanations.
4. Score tracking.
5. Letter grade.
6. Personalized review recommendations based on wrong answers.
7. Responsive design for desktop and mobile.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## How to run
Option 1: Open `index.html` directly in a browser.

Option 2 (recommended on Ubuntu):
```bash
cd interactive-study-guide
python3 -m http.server 8000
```
Then open:
http://localhost:8000

## Suggested presentation/demo
1. Show the four modules.
2. Open one module and show terms + diagram.
3. Start the quiz.
4. Select a wrong answer and show immediate red feedback + explanation.
5. Select a correct answer and show green feedback.
6. Finish the quiz.
7. Show the percentage, letter grade, and recommended review modules.
8. Explain that JavaScript controls the quiz logic and scoring.

## Easy extensions
- Add 20+ questions.
- Add a timer.
- Add student name.
- Save high scores with localStorage.
- Add more subjects.
- Add images/real diagrams.
- Add a teacher/admin question editor.
